# Fuentes de One Hour One Life

Este directorio contiene las fuentes sincronizadas del proyecto original One Hour One Life de Jason Rohrer:

- `OneLife/gameSource/`: Código del cliente en C++ (lógica de juego, interfaz, interacción).
- `OneLife/server/`: Lógica del servidor original (referencia para la simulación offline integrada).
- `minorGems/`: Motor gráfico, matemático y de I/O en C++.
- `OneLifeData7/`: Datos del juego (objetos, transiciones/crafteos, sprites, animaciones y sonidos).
